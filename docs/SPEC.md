# اسپک پروتوتایپ وبسایت شخصی (Persona Site)

پروتوتایپ تک‌صفحه‌ای وبسایت شخصی دوزبانه (فارسی/انگلیسی) با حس محصول‌محور و دارک. محتوا کاملاً ساختگی و AI-generated است. داده واقعی از مالک پروژه استفاده نمی‌شود.

## ۱. هدف و محدوده

یک لندینگ تک‌صفحه‌ای که یک نفر را معرفی کند: هیدر، فوتر، سکشن‌های کامل، فرم تماس پروتوتایپ، و سوییچ زبان FA/EN.

- هدف: پروتوتایپ قابل‌نمایش، نه محصول پروداکشن با بک‌اند
- محتوا: کاملاً ساختگی و AI-generated
- خارج از محدوده: لاگین، CMS، ارسال واقعی ایمیل، بلاگ واقعی، آنالیتیکس، SEO پیشرفته، دیتابیس

## ۲. پرسونای ساختگی

- **نام:** موبین آریا / Mobin Arya
- **نقش:** Product Engineer
- **تمرکز:** ساخت اینترفیس محصول، سیستم‌های دیزاین، ابزارهای AI-assisted
- **موقعیت:** تهران · ریموت
- **وضعیت:** Open to selected collaborations
- **لحن:** دقیق، کوتاه، محصول‌محور؛ نه شعاری

## ۳. استک فنی

- Vite + Vanilla TypeScript
- HTML تک‌صفحه در `index.html`
- استایل: CSS خالص با custom properties (بدون Tailwind)
- محتوا: `src/i18n/en.ts` و `src/i18n/fa.ts`
- زبان انتخاب‌شده در `localStorage` با کلید `persona-lang`
- بدون بک‌اند؛ فرم تماس فقط ولیدیشن کلاینت + استیت موفقیت ساختگی
- تست واحد: Vitest + happy-dom (`npm test`)
- تست مرورگر: Playwright Chromium (`npm run test:e2e`)
- دروازهٔ انتشار: `npm run verify`

اجرا: `npm install` سپس `npm run dev`. منطق خالص فرم و فیلتر کار در `src/lib` است.

## ۴. معماری اطلاعات

تک‌صفحه با انکر:

Header → Hero → About → Work → Experience → Skills → Writing → Contact → Footer

ناو: درباره / About · کارها / Work · مسیر / Experience · مهارت‌ها / Skills · نوشته‌ها / Notes · تماس / Contact

## ۵. سیستم دوزبانه

- دکمه `FA | EN` در هیدر و تکرار کوچک در فوتر
- با تغییر زبان: `document.documentElement.lang` و `dir` (`rtl` برای FA، `ltr` برای EN)
- فونت فارسی: Vazirmatn — فونت انگلیسی: IBM Plex Sans + IBM Plex Mono
- همه متن UI و محتوا از دیکشنری می‌آید
- اعداد در حالت FA به فارسی تبدیل می‌شوند

## ۶. دیزاین سیستم

- پس‌زمینه: `#07090D`
- سطح: `#10141C`
- بوردر: `rgba(255,255,255,0.08)`
- متن اصلی: `#E8EDF5`
- متن ثانویه: `#8B95A8`
- اکسنت: `#3DDC97`
- فاصله پایه: 8px
- شعاع: 2–8px
- بریک‌پوینت: `640 / 768 / 1024 / 1280`
- `prefers-reduced-motion` رعایت می‌شود

## ۷. سکشن‌ها

- **Header:** چسبان، برند ARYA، ناو، سوییچ زبان، CTA، منوی موبایل با فوکوس‌ترپ
- **Hero:** نام، جمله ارزش، متا، CTA، کارت هویت انتزاعی، آمار ساختگی
- **About:** دو پاراگراف + سه اصل کاری
- **Work:** شش پروژه، فیلتر All/Product/Interface/AI، پنل جزئیات اینلاین
- **Experience:** چهار نقش + یک تحصیلات
- **Skills:** چهار گروه با سطح بصری
- **Writing:** سه یادداشت ساختگی بدون ناوبری واقعی
- **Contact:** ایمیل نمایشی، لینک‌های placeholder، فرم با ولیدیشن و موفقیت ساختگی
- **Footer:** ناو، اجتماعی، زبان، بازگشت به بالا، نوت Privacy

## ۸. دسترسی‌پذیری

Skip link، کنتراست تقریبی WCAG AA، فوکوس قابل‌دیدن، `aria-expanded` / `aria-controls`، HTML سمنتیک.

## ۹. آنچه ساخته نمی‌شود

صفحه جدا برای پروژه/بلاگ/حریم خصوصی، بک‌اند، تم روشن، CMS، عکس پرتره واقعی، داده رزومه واقعی.

## ۱۰. نحوهٔ کار روی محصول

دو چت جدا: Product Manager (پایدار) و Implementer (یک‌بارمصرف). قرارداد کامل در `docs/PRODUCT.md` است. پرامپت PM در `docs/prompts/PRODUCT_MANAGER.md` است. بعد از هر تغییر ماهوی، PM تست می‌گیرد و فقط اگر سبز بود به `origin` پوش می‌کند.
