## اجرا (الزامی)

این پروژه Vite است. **فایل `index.html` را مستقیم در مرورگر باز نکن** — اسکریپت‌ها لود نمی‌شوند.

```sh
cd D:\VibeCoding\Cursor\personal-site-prototype
npm install
npm run dev
```

بعد برو به: http://127.0.0.1:3000/

پیش‌نمایش بیلد:

```sh
npm run build
npm run preview
```
